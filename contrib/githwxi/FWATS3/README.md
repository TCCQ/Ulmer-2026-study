# FWATS3: Feather-Weight ATS3

FWATS3 is designed to study core features of ATS3, with a particular focus on
templates and their implementation.

## Purpose

The project aims to provide a formal basis for studying:

- Core features of ATS3.
- The template feature supported by ATS3.
- The implementation of that template feature.

## Project Status

This directory currently contains the project overview. Build, usage, and testing
instructions will be added as the project develops.
